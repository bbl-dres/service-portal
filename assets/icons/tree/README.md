# Symbole des Seitenbaums

Lucide 1.31.0, ISC-Lizenz — https://lucide.dev

Mitgeliefert, nicht nachgeladen: das Portal muss ohne Netz laufen. Und nur
die tatsaechlich benutzten Dateien, nicht der ganze Satz.

Hier stehen die Symbole ALLER Seitenbaeume — Katalog, Liegenschaften,
Bauprojekte, Mietendenportal, Workspace und Plan-Editor. Sie kommen aus
einer Quelle und haben eine Strichstaerke; das Bundes-CD in `assets/icons/`
traegt den Rest des Portals. Die beiden Saetze sollen sich nicht mischen,
am wenigsten in derselben Spalte.

| Datei | wofuer |
|---|---|
| `chevron-right.svg` | Aufklapp-Zeichen jeder Zeile mit Kindern |
| `library.svg` | Katalog — die Wurzel |
| `boxes.svg` | Geschaeftsobjekte |
| `database.svg` | Systeme |
| `list.svg` | Referenzdaten |
| `globe.svg` | Land |
| `map.svg` | Kanton/Region |
| `map-pin.svg` | Ort |
| `folder.svg` | Wirtschaftseinheit |
| `building.svg` | Gebaeude |

| `briefcase.svg` | Bauprojekt |

| `layers.svg` | Geschoss |
| `workflow.svg` | Fachliche Prozesse |
| `app-window.svg` | Kundenportal — die Ablaeufe des Portals selbst |
