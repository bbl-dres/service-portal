# Service portal hero options

The PNG files are the original 1792 x 896 generated illustrations. The matching
`-readme.jpg` files are 1280 x 640, quality-82 derivatives intended for the root
README and social previews.

| Option | Direction | Files |
| --- | --- | --- |
| Connected services | Isometric buildings, documents, maps, data, and workflows around a central gateway | `service-portal-connected-services-v1.*` |
| Guided journey | A continuous service path from request to outcome | `service-portal-guided-journey-v1.*` |
| One portal | Architectural and data layers converging through one red portal | `service-portal-one-portal-v1.*` |
| Painted network | Architectural watercolor above a service-and-data network | `service-portal-painted-network-v1.*` |
| Painted convergence | A painterly flow of services, plans, logistics, and data through one portal | `service-portal-painted-convergence-v1.*` |

The root README currently uses **Painted convergence**. To test another option,
change only the hero image path and keep the lightweight `-readme.jpg` suffix.
